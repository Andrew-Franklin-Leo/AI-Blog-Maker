## 2025-05-14 - Navigation Accessibility and Active States
**Learning:** Combining color-based active states with visual cues like underlines (borders) significantly improves perceivability for users with color vision deficiencies. Adding a 'Skip to content' link is essential for keyboard users to bypass repetitive navigation.
**Action:** Always use `NavLink` with a border-bottom or similar visual indicator for active states, and ensure a skip-link is present in the main layout.
