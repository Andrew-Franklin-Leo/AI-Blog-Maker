## 2025-02-14 - [Navbar Accessibility & Active States]
**Learning:** Combining color-based active states with border-bottom indicators improves perceivability for users with color vision deficiencies. "Skip to content" links in HashRouter apps require manual focus management to avoid route conflicts.
**Action:** Use NavLink with border-b-2 for active states and implement a manual skip-link handler when using HashRouter.
