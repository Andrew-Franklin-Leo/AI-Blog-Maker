## 2025-05-14 - [Navbar Accessibility and Visual Cues]
**Learning:** In SPAs with persistent navigation, keyboard users benefit immensely from a 'Skip to content' link that targets the main content area. Additionally, relying solely on color to indicate active states can be exclusionary for color-blind users; adding a secondary visual cue like a border-bottom improves perceivability for everyone.
**Action:** Always implement 'Skip to content' links and combine color-based active states with borders or underlines in navigation elements.
