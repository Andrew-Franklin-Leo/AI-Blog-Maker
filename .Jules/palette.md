## 2025-05-14 - Accessible Navigation with Skip Links
**Learning:** Adding a "Skip to Content" link is a fundamental yet often overlooked accessibility feature that significantly improves the experience for keyboard users. Combining it with `NavLink` for automatic `aria-current="page"` and visual cues like borders for active states ensures navigation is both perceivable and navigable for all users.
**Action:** Always include a skip link and use semantic navigation components like `NavLink` with distinct visual active states and focus-visible indicators.
